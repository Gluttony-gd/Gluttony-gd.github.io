# Личный сайт-визитка

Одностраничный сайт с админ-панелью в браузере. Контент (тексты, услуги, цены,
вопросы-ответы, контакты, цвета) редактируется прямо на сайте кнопкой «✎» в
правом нижнем углу.

Сайт опубликован на GitHub Pages и доступен по адресу:
**https://gluttony-gd.github.io**

## Структура

```
assets/
├── css/styles.css   ← внешний вид
└── js/
    ├── data.js      ← контент по умолчанию (можно править вручную)
    ├── main.js      ← сборка страницы из данных
    └── admin.js     ← логика админ-панели
```

## Как менять контент

1. Откройте сайт.
2. Нажмите круглую кнопку «✎» справа внизу.
3. Меняйте тексты, услуги, вопросы, контакты и цвета.
4. Нажмите «Сохранить».

Правки хранятся в localStorage браузера (видны только на вашем устройстве).
Чтобы их увидели все посетители, перенесите новые значения в `assets/js/data.js`
и залейте обновлённый файл на GitHub (см. ниже).

## Как обновить сайт после правок файлов

1. Внесите изменения в файлы в этой папке (например, в `data.js`).
2. Закоммитьте и запушьте в ветку `main` репозитория `Gluttony-gd/Gluttony-gd.github.io`.
3. Через 1–2 минуты изменения появятся на сайте.
